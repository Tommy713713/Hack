# AI Canteen Pilot - 使用说明

## 📦 项目简介

这是一个基于MiniMax API的校园用餐推荐系统，由"宁诺干饭学姐"为学弟学妹提供个性化的食堂推荐。

## 🚀 快速开始

### 1. 解压文件
将 `AI_Canteen_Pilot_Final.zip` 解压到任意文件夹

### 2. 在PyCharm中打开
1. 打开PyCharm
2. 选择 "File" → "Open"
3. 选择解压后的文件夹
4. 点击 "OK" 打开项目

### 3. 配置Python解释器
1. 点击 "File" → "Settings" → "Project" → "Python Interpreter"
2. 点击齿轮图标 → "Add..."
3. 选择 "Virtualenv Environment" 或 "Conda Environment"
4. 点击 "OK" 确认

### 4. 安装依赖
在PyCharm终端中运行：
```bash
pip install -r requirements.txt
```

### 5. 运行程序
- **方法1**：点击右上角绿色运行按钮，选择 "AI Canteen Pilot"
- **方法2**：按 `Ctrl+Shift+B` 运行
- **方法3**：按 `F5` 调试运行

## 💬 使用方法

1. **启动程序**后，会看到：
   ```
   👩‍🎓 宁诺干饭学姐已上线！为宁波诺丁汉大学的学弟学妹服务。
   💡 有什么想吃的？学姐帮你推荐～输入'退出'结束对话。
   ```

2. **输入用餐需求**，例如：
   - "有什么好吃的面条吗"
   - "马上上课了，想吃点快的"
   - "预算20块以内，有什么推荐"
   - "想吃西餐"

3. **查看推荐**，学姐会提供：
   - 餐厅名称和位置
   - 人均价格
   - 推荐菜品
   - 排队时间
   - 推荐理由

4. **结束对话**：输入 "退出"

## 🔧 配置说明

### API Key设置
在 `src/ai_canteen_pilot_chat.py` 文件中，找到以下代码并设置你的MiniMax API Key：

```python
api_key = "你的MiniMax API Key"
```

### 学校名称修改
默认学校是"宁波诺丁汉大学"，可以在初始化时修改：

```python
pilot = AICanteenPilot(school_name="你的学校名称", api_key=api_key)
```

## 📝 功能特点

1. **智能推荐**：基于80条小红书学习数据，提供个性化推荐
2. **详细信息**：包含人均价格、推荐菜品、排队时间、推荐理由
3. **学姐身份**：亲切的语气，像真正的学姐一样给建议
4. **上下文理解**：支持多轮对话，理解用户具体需求
5. **位置感知**：根据用户位置（如TB、图书馆）推荐附近餐厅

## ⚠️ 注意事项

1. **网络连接**：需要网络连接才能调用MiniMax API
2. **API Key**：需要自行申请MiniMax Token Plan的API Key
3. **Python版本**：推荐使用Python 3.8+
4. **依赖包**：首次运行前需要安装requirements.txt中的依赖

## 🐛 常见问题

### Q: 运行时提示缺少依赖包？
A: 在终端中运行 `pip install -r requirements.txt` 安装所有依赖

### Q: 提示API Key错误？
A: 检查 `src/ai_canteen_pilot_chat.py` 中的API Key是否正确设置

### Q: 程序运行很慢？
A: 首次启动时会加载学习数据，后续启动会很快

### Q: 如何添加新的学习数据？
A: 在 `initialize()` 方法中添加新的小红书链接，或者手动编辑 `data/canteen_learning_data.json` 文件
