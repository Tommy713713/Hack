# AI Canteen Pilot (智膳领航员)

基于MiniMax Token Plan的校园精准用餐决策助手

## 项目简介

AI Canteen Pilot 是一个AI驱动的校园用餐推荐应用，能够自动从网上学习食堂信息，并基于学习到的数据为学生提供个性化的用餐推荐。

## 主要功能

- **智能学习**：自动从百度、搜狗、360搜索等平台学习食堂信息
- **URL学习**：支持从小红书、大众点评、美团等链接学习具体食堂信息
- **个性化推荐**：基于用户的口味偏好、预算、时间等提供个性化推荐
- **持久化存储**：学习到的信息会保存到本地，下次启动自动加载
- **多轮对话**：支持上下文理解，保持对话连贯性

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. **运行程序**：
```bash
python src/ai_canteen_pilot_chat.py
```

2. **输入用餐需求**：
   - 例如："随便吃点"、"我想吃辣的"、"有什么好吃的"
   - 或者提供小红书链接让AI学习

3. **与AI对话**：
   - AI会基于学习到的食堂信息为你提供推荐
   - 可以询问具体的食堂、菜品、价格等信息

4. **结束对话**：
   - 输入"退出"结束对话

## 配置说明

在 `src/ai_canteen_pilot_chat.py` 文件中，你可以修改以下配置：

- **学校名称**：默认是"宁波诺丁汉大学"，可以修改为其他学校
- **API Key**：需要设置MiniMax Token Plan的API Key
- **搜索关键词**：可以修改搜索关键词以获取不同学校的食堂信息

## 数据来源

AI会从以下平台自动学习食堂信息：
- 百度搜索
- 搜狗搜索
- 360搜索
- 小红书（通过URL）
- 大众点评（通过URL）
- 美团（通过URL）

## 技术栈

- Python 3.x
- MiniMax API (AI对话)
- BeautifulSoup (网页解析)
- Requests (HTTP请求)

## 注意事项

1. **API Key**：需要自行申请MiniMax Token Plan的API Key
2. **网络连接**：需要网络连接才能从网上学习信息
3. **数据隐私**：学习到的数据仅保存在本地，不会上传到云端
